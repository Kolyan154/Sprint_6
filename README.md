# Sprint_6
# Проект автоматизированного тестирования сервиса аренды самокатов https://qa-scooter.praktikum-services.ru/

## Файлы:
- tests/ - директрория с тестами.
- conftest - содержит фикстуры для тестов
- pages/ - набор методов для тестов
- locators - локаторы

  ### Для запуска тестов должны быть установлены:
`pytest`
`selenium`
`allure`
### Команда для запуска тестов:
`python -m pytest tests/ -v`
